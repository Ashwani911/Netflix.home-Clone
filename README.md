A responsive Netflix Clone developed using HTML and CSS, designed to replicate the look and feel of the original Netflix landing page. The project focuses on modern UI/UX design, responsive layouts, and frontend development concepts.

✨ Features
Responsive Netflix-inspired UI
Hero banner with overlay effects
Navigation bar with language selector
TV and mobile streaming sections
Embedded autoplay videos
Interactive hover effects
Modern dark-themed design
🛠️ Technologies Used
HTML5
CSS3
📚 Learning Outcomes

This project helped improve my skills in responsive web design, CSS positioning, Flexbox, Grid layouts, and modern frontend styling techniques.

🚀 How to Run
Download or clone the repository
Open index.html in any modern browser
